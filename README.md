# Python Programs Collection

A collection of Python programs, automation scripts, networking tools, and problem-solving projects created for learning and practical implementation.

## Topics Covered

- Python Basics
- Object-Oriented Programming
- File Handling
- Automation Scripts
- Networking Programs
- Cybersecurity Tools
- Socket Programming
- Data Structures & Algorithms
- Mini Projects

## Featured Projects

### TCP Port Scanner
A simple Python-based TCP port scanner used to identify open ports on a target machine.

### FTP Server
Basic FTP server implementation using Python socket programming.

### Password Cracker Simulator
Educational brute-force password cracking simulator for learning cybersecurity concepts.

### Socket Programming Projects
Client-server communication programs using Python sockets.

## How to Run

1. Clone the repository

```bash
git clone https://github.com/purushottamcuj62045-alt/Python-Programs.git
```

2. Open the project folder

```bash
cd Python-Programs
```

3. Run any Python file

```bash
python filename.py
```
